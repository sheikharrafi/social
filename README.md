# Portfolio Website

A responsive, single-page portfolio website for a product designer and front-end developer. It is built with semantic HTML, modern CSS, and a small JavaScript enhancement for the mobile menu.

## Files

- `index.html` — page structure and portfolio content
- `styles.css` — responsive visual design, layout, and components
- `script.js` — accessible mobile navigation toggle

## Run locally

Serve the directory with any static file server, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.
